# Sundial for Apple platforms

The Sundial celestial instrument for iPhone, iPad and Apple Watch: a port of the Android app
(`../sundial-android-native`) that draws the same instrument, pixel for pixel, from Swift.

| Folder | What it is |
|---|---|
| `Package.swift`, `Sources/`, `Tests/` | **SundialKit**, a Swift package: the astronomy, calendars and settings (`SundialCore`), the instrument drawn on a platform-neutral canvas (`SundialRender`), a Core Graphics canvas for the apps (`SundialCoreGraphics`), an SVG canvas for Linux (`SundialSVG`) and the `sundial-render` command line |
| `Apps/` | The Xcode project (generated by XcodeGen from `Apps/project.yml`): the iOS app with its widgets, and the watchOS app with its complications. See [`Apps/README.md`](Apps/README.md) |
| `Assets/` | The font, Earth texture and 1024 px app icon the apps bundle |
| `AppStore/` | App Store Connect metadata, privacy answers, the Apple section of the privacy policy, and draft screenshots |
| `docs/` | [`PORTING.md`](docs/PORTING.md) (how the Kotlin maps to Swift), [`APPS.md`](docs/APPS.md) (the apps' architecture) and [`RELEASE.md`](docs/RELEASE.md) (from Developer Program to App Store) |
| `tools/compare_renders.py` | Renders the Android reference scenes with the Swift port and compares them pixel by pixel |
| `.github/workflows/` | `apple.yml` (tests, simulator builds and App Store screenshots on every push) and `testflight.yml` (archive, sign and upload on a `v*` tag) |

## SundialKit without a Mac

SundialKit builds and tests on Linux with a Swift 6 toolchain (the apps themselves need Xcode):

```bash
swift test
```

The tests include `AndroidReferenceTests`, which check the astronomy, calendar and geometry
against values written by the Android app's `SwiftReferenceTest`, and a bit-exact port of
Kotlin's `Random` for the star field.

`sundial-render` draws any scene to SVG (and PNG, through headless Chrome):

```bash
swift run sundial-render --view helio --style brassWatch --layout phone --width 1080 --height 2160 \
  --density 2 --astrology --birth-date 1990-04-18 --assets Assets --out helio.svg --png helio.png
```

`tools/compare_renders.py` renders every scene of the Android `ReferenceRenderCapture` and
writes side-by-side sheets and a difference summary to `renders/compare/`. Pull the Android
captures to `renders/android/` first (see the script's header).

## The apps

Open `Apps/Sundial.xcodeproj` in Xcode 27 on a Mac, or let CI build them: every push runs the
`Apple` workflow on a GitHub macOS runner, which tests SundialKit, builds the iOS and watchOS
apps for the simulators and captures the App Store screenshots. Releasing, including uploading
to TestFlight from GitHub Actions without a Mac, is in [`docs/RELEASE.md`](docs/RELEASE.md).
